# Every-step ordering by a parameter score

Data seeds [0, 1, 2]. Each run starts from the same pretrained full GP, then takes 1000 prefix-NLPD steps. The order is recomputed after every step and always used.

Conditional KL grows the prefix by the increase in KL(q(u_A)||p(u_A)). KL × diversity multiplies the marginal KL by the prior conditional-variance fraction. Marginal KL ranks each point on its own. The deletion score is |alpha_j| / Q_jj. None of these scores uses labels or enters the training loss. Greedy every step, fixed greedy, and random-subset + greedy are baselines from the saved runs, restricted to these seeds.

↓ lower is better. **Bold** is the best mean in that column. For a difference, negative favors the first method.

## Order changes

A change is a step whose ranking differs from the previous one.
