# Greedy initialization plus prefix training

One pretrained full GP per draw, then 1000 prefix steps. Data seeds [0, 1, 2, 3, 4]. Ordering and acceptance use the selection split. The test split is reported only here.

A fixes a random permutation. B stops after the greedy order. C trains prefixes on that fixed greedy order. D replaces the order every 200 steps only when the average selection NLPD at budgets 4, 8, and 16 improves. E recomputes that greedy order after every parameter update and always uses it. Random-subset training starts from the same checkpoint and receives one greedy order at the end.

↓ lower is better. **Bold** is the best mean in that column. For a difference, negative favors the first method.
